Shotlane provides a real browser service for AI agents and code, rendering web pages into screenshots, PDFs, Markdown, and scrolling videos using current Chrome. Users can obtain a free API key for up to 100 renders per month, with paid credits never expiring. The platform supports integrations with ChatGPT, Claude, Cursor, and other MCP clients, offering tools for removing cookie banners, pop‑ups, ads, and chat widgets. It also offers bulk jobs, monitoring, and storage options, catering to developers needing clean page captures for AI, RAG, or testing purposes.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Shotlane: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
